# Client Recommendations

## Client A – Startup Company

*Recommended Platform: AWS*

AWS is recommended for the startup company because it provides flexible and scalable cloud services. The company can start with small resources and increase them as the mobile application grows. AWS also provides many services that can support application hosting, storage, and databases. This makes it suitable for a startup with a limited budget but expecting rapid growth.

*Services:*
- Amazon EC2
- Amazon S3
- Amazon RDS

## Client B – University

*Recommended Platform: Microsoft Azure*

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure integrates well with Microsoft technologies, which can make cloud migration easier. It can also support hybrid environments where some systems remain on-premises while others move to the cloud. This makes Azure a practical choice for the university.

*Services:*
- Azure Virtual Machines
- Azure Blob Storage
- Microsoft Entra ID

## Client C – AI Research Company

*Recommended Platform: Google Cloud Platform (GCP)*

Google Cloud Platform is recommended for the AI research company because it offers strong services for artificial intelligence and machine learning. GCP also provides computing resources that can support demanding research workloads. Its tools can help researchers process large amounts of data and develop AI applications. This makes GCP a strong choice for high-performance AI workloads.

*Services:*
- Compute Engine
- Vertex AI
- Google Kubernetes Engine

## Client D – Global E-Commerce Company

*Recommended Platform: AWS*

AWS is recommended for the global e-commerce company because it has a large global infrastructure and supports highly available applications. It can automatically scale resources when customer traffic increases. AWS also provides services for content delivery, storage, and computing across different locations. This helps the company serve customers around the world reliably.

*Services:*
- Amazon EC2
- Amazon S3
- Amazon CloudFront

# Checkpoint 6 - Multi-Cloud Decision Matrix

The following decision matrix recommends the most suitable cloud platform based on different business requirements.

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS provides flexible and scalable cloud services that can support a startup as it grows. |
| Enterprise Organization | AWS | AWS offers a broad range of cloud services suitable for large and complex enterprise workloads. |
| Microsoft Environment | Microsoft Azure | Azure integrates well with Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory. |
| AI / Machine Learning | Google Cloud Platform (GCP) | GCP provides strong tools and services for artificial intelligence, machine learning, and data analytics. |
| Kubernetes Deployment | Google Cloud Platform (GCP) | GCP provides Google Kubernetes Engine (GKE) for deploying and managing containerized applications. |
| Global Web Application | AWS | AWS has a large global infrastructure that can support highly available and scalable web applications. |
